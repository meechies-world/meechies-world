# MeechieBot AI Brain

The free AI brain for **MeechieBot Studio** (meechiesworldinc.com/livebot/), a Meechie's World Inc product.
It runs on the buyer's own free Cloudflare account, so their replies and voice use their own free Workers AI allowance.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/meechies-world/meechies-world/tree/main/tools/livebot-brain)

After deploying, copy the Worker link (`https://meechiebot-brain.<you>.workers.dev`) into MeechieBot Studio.
